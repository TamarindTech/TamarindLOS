# Code of Conduct

Tamarind LOS adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** as its code of conduct.

## Our commitment

We want Tamarind to be a welcoming, respectful and harassment-free community for everyone, regardless of background or experience. We expect all participants (in issues, pull requests, discussions and any project space) to:

- Be respectful and constructive, especially when disagreeing.
- Assume good intent and give helpful, specific feedback.
- Focus on what is best for the project and its users.
- Accept responsibility for mistakes and learn from them.

Harassment, personal attacks, discriminatory language, and publishing others' private information are not acceptable.

## Scope

This code applies in all project spaces, and when someone officially represents the project in public.

## Reporting

If you experience or witness unacceptable behaviour, contact the project maintainer, Christopher Tun (GitHub: @kochrisdev), privately. Reports will be reviewed promptly and handled confidentially.

## Enforcement

Maintainers will follow the enforcement guidelines of the Contributor Covenant 2.1: correction, warning, temporary ban or permanent ban, depending on severity.
